# Digital Systems Laboratory

This repository contains the experiments and projects completed for the Digital Systems Laboratory course.

## Experiments

### 1. Combinational Logic Circuits

This experiment focuses on the design and implementation of basic combinational logic circuits using Boolean expressions and logic gates.

**Topics:**
- Logic gates
- Boolean algebra
- Combinational circuit design
- Simplification of logic functions

---

### 2. Sequential Logic Circuits

This experiment covers the design and analysis of sequential digital circuits.

**Topics:**
- Flip-flops
- Registers
- Counters
- State-based digital systems

---

### 3. Finite State Machines

This experiment focuses on the design and implementation of finite state machines for digital control systems.

**Topics:**
- Principles
- Moore and Mealy machines
- State diagrams
- State transitions
- Sequential control logic

---

### 4. Verilog/VHDL Design

Digital circuits are described and simulated using a hardware description language.

**Topics:**
- Module design
- Testbenches
- Simulation and verification

---

### 5. FPGA Implementation

Designed digital systems are implemented and tested on an FPGA development board.

**Topics:**
- FPGA-based digital design
- Hardware synthesis
- Pin assignment
- Hardware testing and verification

---

## Tools

- Verilog
- FPGA Development Board
- Vivado
